# 开发环境搭建指南

> 适用版本：CetCryptoToolkit v2.3.x
> 平台：Windows 7 / 10 / 11

---

## 一、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Qt | **5.15.2** | 必须使用此版本 |
| 编译器 | **MinGW 32-bit** | 必须是 32-bit，不可用 64-bit 或 MSVC |
| OpenSSL | 3.x（3.0.18） | 已预置在 `libs/` 目录，无需单独安装 |
| CMake | 3.16+（可选） | 使用 CMake 构建时需要 |
| Git | 任意版本 | 代码管理 |

> ⚠️ **关键约束**：项目链接的 OpenSSL DLL 为 32-bit 版本，编译器必须选择 MinGW **32-bit**，否则链接时会报架构不匹配错误。

---

## 二、Qt 安装

### 2.1 下载 Qt 在线安装器

从 Qt 官网下载 `qt-unified-windows-x86-online.exe`，或使用离线安装包 `qt-opensource-windows-x86-5.15.2.exe`。

### 2.2 安装时选择组件

在组件选择界面，展开 **Qt 5.15.2**，勾选：

```
Qt 5.15.2
  ✅ MinGW 8.1.0 32-bit        ← 必选
  ✅ Qt Network                 ← 必选（提供 QSslKey / QSslCertificate）
  ✅ Qt Widgets                 ← 必选

开发工具
  ✅ MinGW 8.1.0 32-bit        ← 编译器本体
  ✅ Qt Creator                 ← 推荐 IDE
```

### 2.3 验证安装

```bash
# 在 Qt Creator 的 Terminal 或 MinGW 命令行中执行
qmake --version
# 期望输出：QMake version 3.1 / Using Qt version 5.15.2 in ...mingw81_32...
```

## 四、构建项目

### 4.1 qmake 构建（推荐）

```bash
# 进入源码子目录
cd CetCryptoToolkit

# 生成 Makefile
qmake CetCryptoToolkit.pro -spec win32-g++ CONFIG+=release

# 编译（-j4 表示 4 线程并行）
mingw32-make -j4
```

Debug 构建：

```bash
qmake CetCryptoToolkit.pro -spec win32-g++ CONFIG+=debug
mingw32-make -j4
```

### 4.2 Qt Creator 构建（推荐新手）

1. 打开 Qt Creator → **文件** → **打开文件或项目**
2. 选择 `CetCryptoToolkit/CetCryptoToolkit.pro`
3. 在 Kit 选择界面，选择 **Qt 5.15.2 MinGW 32-bit**
4. 点击左下角 **构建** 按钮（或 `Ctrl+B`）

### 4.3 CMake 构建（备选）

```bash
cd CetCryptoToolkit
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 4
```

## 五、运行时 DLL 部署

编译完成后，可执行文件需要以下 DLL 在同目录：

```bash
# 使用 windeployqt 自动部署 Qt 运行时
windeployqt.exe CetCryptoToolkit.exe

# 手动复制 OpenSSL DLL（从 libs/ 目录）
copy libs\libcrypto-3.dll <输出目录>
copy libs\libssl-3.dll    <输出目录>
```

完整运行时目录结构：

```
CetCryptoToolkit.exe
libcrypto-3.dll
libssl-3.dll
Qt5Core.dll
Qt5Gui.dll
Qt5Widgets.dll
Qt5Network.dll
platforms\qwindows.dll
plugins\                    ← 可选：商业功能插件
Configs\AppMaster.ini       ← 首次运行后自动生成
```

## 六、插件部署（可选）

商业功能插件（授权/更新/日志）放置在以下任一路径：

```
# 优先路径（生产环境）
D:\Program Files (x86)\CetXiyuan\CetToolDLLs\plugins\

# 备用路径（开发/便携模式）
<exe同目录>\plugins\
```

插件缺失时程序会弹出警告，但核心密码学功能不受影响。

## 七、常见问题

**Q：编译报错 `undefined reference to __imp_EVP_...`**

A：OpenSSL 库架构不匹配。确认使用的是 MinGW **32-bit** 工具链，而非 64-bit。检查 Qt Creator 中 Kit 配置的编译器路径是否包含 `mingw81_32`。

---

**Q：运行时报错 `无法找到 libcrypto-3.dll`**

A：将 `libs/libcrypto-3.dll` 和 `libs/libssl-3.dll` 复制到 `.exe` 同目录。

---

**Q：界面中文显示乱码**

A：项目已在 `main.cpp` 中设置 `QTextCodec::setCodecForLocale`，通常不会乱码。若仍有问题，检查源文件编码是否为 UTF-8，Qt Creator 中可在 **工具 → 选项 → 文本编辑器 → 行为** 中设置默认编码为 UTF-8。

---

**Q：Qt Creator 提示 `Cannot find kit`**

A：进入 **工具 → 选项 → Kits**，确认存在一个 Kit 使用 Qt 5.15.2 MinGW 32-bit 编译器，且 Qt 版本指向正确的 `qmake.exe`。

---

**Q：`qmake` 命令找不到**

A：将 Qt 的 MinGW 32-bit bin 目录加入系统 PATH，例如：

```
C:\Qt\5.15.2\mingw81_32\bin
C:\Qt\Tools\mingw810_32\bin
```

---

**Q：插件加载失败，弹出警告**

A：这是正常现象，商业插件（授权/更新）不影响密码学核心功能。如需完整功能，将对应 DLL 放入 `plugins/` 目录。

---

## 八、开发调试建议

- 使用 `qDebug()` 输出调试信息，程序定义了 `QT_MESSAGELOGCONTEXT`，日志会包含文件名和行号
- 按 **F2** 可快速打开程序工作目录，方便查看生成的证书文件
- 证书输出目录：`<工作目录>/dir-certs/`
- 配置文件：`<工作目录>/Configs/AppMaster.ini`
