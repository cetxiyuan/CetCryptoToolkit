变更日志

本文档遵循 Keep a Changelog 规范。

版本号遵循 语义化版本。

[2.5.0] - 2026-07-09

重大版本：许可 3.0 + CetToolPluginContext 重构

Added

  • 引入 `CetToolPluginContext` 统一管理插件加载，支持 DLL SHA256 完整性校验
  • 许可插件支持 Ed25519 签名验证（许可 3.0）
  • 支持临时授权、停用/拒绝状态，拒绝后停止自动重试

Changed

  • 重构 MainWindow，插件相关逻辑移交 `CetToolPluginContext` 统一管理
  • 更新插件（CetUpdatePlugin）支持 2 位数版本号
  • 许可证激活定时器重构为可复用 QTimer
  • 许可周期超过 24 小时后从 10 分钟开始重置

[2.4.0] - 2026-06-25

许可 2.0

Changed

  • 许可插件更新至 2.0 版本

Fixed

  • 上电首次自动激活改为 30 秒延迟

[2.3.2] - 2026-06-08

Fixed

  • 修复升级功能容易失败的问题（延长超时 10 秒、去掉 HTTP 请求超时设置）
  • 修复 `cetlicenseinterface.h` 中 `ActivateResult` 拼写错误

Changed

  • 更新 CetCANPlugin 和 CetLicensePlugin 插件

[2.3.1] - 2026-05-07

Fixed

  • 修复产品固钥和本地地址的绑定关系异常问题

[2.3.0] - 2026-03-06

基准版本

Changed

  • 授权插件（CetLicensePlugin.dll）远程授权请求间隔改为每 20 分钟一次
  • 主进程授权激活策略调整为渐进式：首次 10 秒 → 30 分钟 → 60 分钟 → 120 分钟，依次类推

Added

  • 添加 F2 快捷键支持，可快速打开程序当前工作目录
  • 添加 `.gitattributes` 文件规范 Git 换行符处理
  • 集成 OpenSSL 3.0.18 源码库

[2.2.0.2271] - 2026-02-27

补丁版本（Patch-2271）

Added

  • 终端证书生成时，主界面新增「颁发者」指示功能，显示当前使用的签发 CA 类型

Fixed

  • 一级根证书（Custom）现在可按用户配置的参数正确生成

[2.2.0] - 2026-02-09

基准版本

Fixed

  • 加载许可时先清空已有许可码，避免残留数据干扰

[2.1.2] - 2026-01-31

Fixed

  • 激活方式改为新的渐进式策略：首次 10 秒 → 30 分钟 → 120 分钟 → 480 分钟，依次类推
  • 授权插件（CetLicensePlugin）逻辑全面修订：
  • 许可内容未发生变化时不再重复写入文件
  • 授权表中被禁用的用户，直接删除其许可文件
  • 远程许可申请改为在许可到期前第 5 天开始发起
  • 每次激活不再重新刷新许可创建日期

    [2.0.0] - 2025-12-15

    重大版本：国密支持 + OpenSSL 3.x 升级

    Added

    • 全面支持国密算法：SM2（公钥加密/签名）、SM3（摘要）、SM4（对称加密）
    • SM2 证书签发支持（配合 `hashAlgo=sm3`）

    Changed

    • 底层 OpenSSL 库升级至 3.0.18（`libcrypto-3.dll` / `libssl-3.dll`）
    • 替换 OpenSSL 1.1.1t 为 OpenSSL 3.x API 风格

    [1.0.0] - 2025-11-20

    初始发布版本

    Added

    • 基于 Qt 5.15.2 (MinGW 32-bit) 的密码学工具箱桌面应用
    • 证书管理：支持三级 PKI 体系（RootCA / SubCA / EndEntity）
    • 非对称加密：RSA / EC 密钥对生成、加解密、签名验签
    • 对称加密：AES（ECB/CBC/GCM/CTR）
    • 摘要计算：MD5 / SHA1 / SHA256 / SHA512 等
    • 插件架构：支持动态加载授权、更新、日志等功能插件
